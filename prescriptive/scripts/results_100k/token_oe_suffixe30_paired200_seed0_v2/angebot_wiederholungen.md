# Zusätzliche Angebote nach Besuch des Wahlpunkts

Aus den vollständigen Entscheidungsprotokollen des gepaarten Kurztests: Seed 0, 30 Ziehungen, 200 gewertete Fälle.

| Variante | Besuch | Entscheidungen | Zusätzliches Angebot |
|---|---|---:|---:|
| ohne_sperre | 1 | 194 | 41.8 % |
| ohne_sperre | 2 | 97 | 45.4 % |
| ohne_sperre | 3 | 49 | 53.1 % |
| ohne_sperre | 4+ | 87 | 60.9 % |
| mit_sperre | 1 | 197 | 47.7 % |
| mit_sperre | 2 | 107 | 48.6 % |
| mit_sperre | 3 | 60 | 63.3 % |
| mit_sperre | 4+ | 127 | 61.4 % |

Spätere Besuche betreffen eine andere Auswahl von Fällen. Die steigende Quote allein beweist deshalb keinen falschen individuellen Effekt. Sie begründet einen gezielten Test, bei dem PSP nur am ersten Angebot entscheidet und spätere Entscheidungen der Bank überlässt. Das würde prüfen, ob wiederholtes Eingreifen einen wesentlichen Anteil des Rückstands erklärt.
